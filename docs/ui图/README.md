# 电商运营智能助手 UI 设计

依据 PRD v1.0 与 Spec v1.1，共 25 张画板，保存在本目录 `.pen`，使用 VS Code 的 Pencil / pen.dev 打开。

覆盖设计系统、登录、经营看板、店铺、商品/SKU、竞品、日经营数据、CSV 预检与覆盖确认、六类 AI 创建、任务中心、草稿、人工审核、历史与导出、团队权限、模型配置、审计及关键异常状态。所有姓名、店铺和经营数据均为演示。

最终画板通过实际 Pen MCP 的 execute 编辑，使用 TakeScreenshot 检查中文显示，Get 全画布检查未发现裁切或溢出。经营看板为 1440×1240，其余画板为 1440×1060，画板每行排列 4 张。预览目录包含由 Pen 原生 Export 导出的 6 张 PNG。

中文字体 Noto Sans SC 位于 fonts，使用 SIL Open Font License，许可证见 fonts/OFL.txt。字体已通过 Pencil Custom Fonts 导入；请保留字体资源一起交接，其他电脑若缺字可在 Custom Fonts 导入该文件。

AI 内容初始为草稿；审核绑定具体版本，作者不可自审；正式导出仅对已通过版本开放；CSV 有错误不能入库，覆盖需确认；缺失经营日期不补零。界面是设计产物，未实现业务接口和交互。
