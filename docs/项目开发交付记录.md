## 后续直接启动

本机Docker Desktop需运行；在项目根目录：

```powershell
docker compose -p ecommerce-operation-local --env-file .local/mysql84.env up -d --pull never mysql
```

分别在backend、backend、frontend三个终端执行：

```powershell
uv run uvicorn app.main:app --reload --host 127.0.0.1 --port 8000
uv run python -m app.worker
npm run dev
```

后端虚拟环境仍由uv管理。数据库容器重启后卷内数据保留；不要使用`down -v`删除交付数据卷。`.local`中的凭据/配置与云端原配置都不进入Git。

## 云服务器切换说明

项目的部署目标仍是云服务器；当前本机验证已作为本轮开发结项依据。服务器恢复、真实Key配置/评测和生产容量/备份演练属于后续部署与使用配置，尚未宣称完成。

原云连接完整配置已保存在`.local/backend.cloud.env`，本机连接副本在`.local/backend.local.env`。服务器恢复后，先确认云库现有数据并备份，再将backend/.env中的DB_HOST/PORT/NAME/USER/PASSWORD/TLS切换为云端实际值；或者使用保留的云配置副本。主密钥须与云端历史模型配置匹配，不随迁移任意替换。

在backend执行`uv run python -m app.cli check-db --connection-only`，连接成功并完成云库备份后，再执行`uv run alembic upgrade head`、`uv run alembic check`、`uv run python -m app.cli check-db`，最后重启API/Worker。不会把本机业务数据自动覆盖到云库；如需迁移本机数据，应另行按备份恢复说明操作。完整应用云端部署命令见《应用发布与备份恢复》。
