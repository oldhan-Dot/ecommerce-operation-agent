- AES-256-GCM、随机 12 字节 nonce；附加认证数据绑定企业、配置版本、服务商、端点、模型名及主密钥标识。数据库保存密文，接口固定掩码，日志/审计不保存原密钥；保存后的输入框清空，不持久化浏览器密钥。

- 更新时 API Key 留空沿用当前密钥，重新加密到新版本，旧记录保留。主密钥不匹配或密文认证失败时明确拒绝解密；重新输入 API Key 可保存新配置，不把更换主密钥伪装成已完成历史密钥轮换。

## 后续小功能

### 已完成：供应商网络适配器（2026-10-17）

- 新增 `backend/app/model_provider.py`，提供单次 DeepSeek 探测函数；只发送固定探测文字，不携带业务数据，最多生成 16 个 token。
- 请求前重新校验官方 HTTPS 地址及服务端白名单；DNS 全部结果必须为公网地址，拒绝混合私网、环回、链路本地、组播及 IPv4 映射地址。将 TCP 目标固定为校验后的 IP，HTTP Host、TLS SNI、证书名称校验继续使用 `api.deepseek.com`。
- 使用显式 httpcore 连接池及默认可信证书，无环境代理、重定向、自动重试或跨请求连接复用。连接、读、写分别限时，外层总超时包含 DNS 及完整响应读取；正文累计上限 1 MiB，拒绝压缩编码。
- 返回延迟与三个白名单 token 计数，不返回模型正文、密钥、原始供应商错误或任意 usage 字段。非 200、空正文、无效 JSON、超限及网络错误返回固定错误码和消息。
