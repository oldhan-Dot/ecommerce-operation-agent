# 本机开发环境

本机 Python 3.12 + uv 项目隔离，云端 MySQL 8.4，前端 Vue 3 + Vite。云端 MySQL 已由用户部署，本次不改云服务器、数据库账号、安全组或原 Compose 配置。

## 配置数据库

在 `backend/.env` 中填写：

```dotenv
DB_HOST=你的服务器公网IP
DB_PORT=3306
DB_NAME=ecommerce_agent
DB_USER=ecommerce_app
DB_PASSWORD='你的应用账号密码'
DB_TLS_MODE=DISABLED
```

密码是服务器 Compose `.env` 中 MYSQL_PASSWORD 对应的值，不是 root 密码。不要把密码发到聊天或提交 git。项目根目录的 `.env` 用于云端 Compose；`backend/.env` 用于本机 API/Worker，两者分开。

本机配置保留独立加密主密钥和会话 pepper；SESSION_PEPPER 至少32字符，ENCRYPTION_KEY为32字节Base64URL值，二者独立生成并保存。加密主密钥丢失后无法解密历史模型Key。模型域名白名单配置 `ALLOWED_MODEL_HOSTS=["api.deepseek.com"]`。开发按用户约定不强制数据库TLS；生产不允许DISABLED。

## 安装或重建依赖

在 backend 目录：

```powershell
uv venv --python 3.12
uv sync --frozen --cache-dir .local/uv-cache
```

在 frontend 目录：

```powershell
npm ci --cache .local/npm-cache --no-audit --no-fund
```

依赖安装在 backend/.venv 与 frontend/node_modules，不修改系统 Python，不全局安装 Node 包。uv.lock 和 package-lock.json 应作为后续开发文件保留。

## 验证连接并执行业务迁移

在 backend 目录：

```powershell
uv run python -m app.cli check-db --connection-only
uv run alembic upgrade head
uv run python -m app.cli check-db
```

首条只检查连接，不打印数据库密码。当前迁移到`0016_observation_indexes`，包括数据基础、导入、模型配置/调用、任务快照/产出、审核版本及Worker心跳。迁移是显式命令，API/Worker不会自动改库。

随后交互创建首个管理员（没有默认密码，也不会自动创建演示账号）：

```powershell
uv run python -m app.cli create-admin --username admin
```

密码在本机终端交互输入，不放入参数或聊天。账号重名时命令拒绝覆盖。普通成员由管理员在页面中创建，第一次使用临时密码登录后须先改密。

## 可选：已有启动与停止辅助脚本（Windows PowerShell）

用户约定优先使用下面的直接开发命令。本节仅保留已有辅助入口，脚本文件头已说明用途。

在项目根目录：

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\start-dev.ps1
```

该参数仅作用于本次启动，不修改机器执行策略。脚本后台运行三个服务，不弹出终端；如端口已被占用则报错，不杀其他项目进程。脚本直接使用 uv 创建的项目 .venv Python，后台环境不依赖全局包。

- 前端：http://127.0.0.1:5173
- API 文档：http://127.0.0.1:8000/api/docs
- API 存活：`/api/v1/health/live`
- API 就绪：`/api/v1/health/ready`，数据库未配置/不可连接/未迁移时返回 503，不伪装为已就绪。
- Worker：独立进程，执行CSV预检/确认/清理、六类AI生成/恢复和心跳。上传或提交AI任务后保持Worker运行；仅启动API不能执行排队任务。
- 日志：项目 `.local` 目录。Worker 状态变化时才记录，避免刷屏。

停止：

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\stop-dev.ps1
```

修改 backend/.env 后需要重启服务，才会重新载入配置。脚本通过 PID、启动时间和执行路径核对自己启动的进程，不关闭其他项目。

## 推荐：直接命令开发模式

分别在三个终端执行：

```powershell
# backend 目录，终端一
uv run uvicorn app.main:app --reload --host 127.0.0.1 --port 8000
# backend 目录，终端二
uv run python -m app.worker
# frontend 目录，终端三
npm run dev
```

前端通过 Vite 将 /api 代理到本机 8000，无须开放后端公网端口。端口固定并启用 strictPort，避免自动换端口造成代理错配。
